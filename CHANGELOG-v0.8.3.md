# FM Data Center v0.8.3

- Novo Debug Clubes com auditoria por clube e época.
- Deteção de reputação, país, continente, liga nacional, treinadores, jogadores, estatísticas, classificações, duplicados e conflitos de nomes.
- Correção manual de clubes, associação de treinadores, remoção de ligações duplicadas e sincronização de referências.
- Debug Países expandido com seleções sem treinador ou com vários selecionadores.
- Novo Debug Relações para registos órfãos, referências quebradas, nomes divergentes, identidades duplicadas e valores inválidos.
- Correções automáticas seguras e exportação JSON dos diagnósticos.
